[공유·이름·보존 기준](../ENGINEERING-STANDARDS.md#공유-연구-영수증)을 적용한다.
공유 초안은 PR 리뷰와 병합으로 채택하며, 연구 자료 채택과 실행·배포·모델 승격 근거를
구분한다. 원시 로그와 큰 생성물은 외부 생성물 루트에 보관한다.

## 식별과 출처

| 항목 | 기록 |
|---|---|
| 작성 시점 | UTC 시각 입력 |
| 마지막 정정 시점 | UTC 시각 또는 해당 없음과 이유 |
| GitHub 작성자·공동 작성자 | 확인한 공개 로그인명과 프로필 링크 |
| 관련 PR·이슈·후속 기록 | 공개 링크 또는 해당 없음과 이유 |
| 저장소·기준 commit SHA | OWNER/REPO와 정확한 SHA |
| 미커밋 변경 | 없음 또는 영향 파일의 저장소 상대 경로와 재현 근거 |
| 자료 유형 | 조사 / 규칙 비교 / 검증 / 성능 실험 / 실패 분석 |
| 관측 근거의 범위 | 소스 조사 / 로컬 실행 / CI 요청 / 관측한 CI 결과 / 모델 성능 검증 중 실제 범위 |

## 재현 설정

### 입력과 버전

| 항목 | 기록 |
|---|---|
| 입력·fixture·데이터 | 저장소 상대 위치 또는 공유 참조, 필요한 hash |
| 모델·어댑터·encoder·규칙·catalog | 관련 버전과 hash 또는 해당 없음과 이유 |
| seed·옵션·비교 조건 | 실제 사용한 값 또는 해당 없음과 이유 |

### 환경과 실행 한도

결과에 영향을 주는 규격만 기록한다. 로컬 계정명·실명·호스트명·개인 이메일·
장치 식별자와 절대 파일 경로를 넣지 않는다.

| 항목 | 기록 |
|---|---|
| OS·아키텍처·도구 버전 | 실제 관련 버전 |
| CPU·GPU·메모리 | 관련 규격 또는 해당 없음과 이유; 개인 장비 이름·일련번호 제외 |
| worker·batch·스레드 | 실제 설정 또는 해당 없음과 이유 |
| 작업·step·시간·메모리 예산 | 유한한 실행 한도 또는 소스 조사 등 해당 없음의 이유 |
| 종료·취소·자식 프로세스 정리 | 사용한 조건과 방법 또는 해당 없음과 이유 |

### 명령과 작업 디렉터리

작업 디렉터리는 저장소 루트 또는 저장소 상대 경로로 적는다.
`${ARTIFACT_ROOT}`는 생성물 루트의 문서용 기호이며 실행 시 환경에 맞게 지정한다.
확장된 로컬 값을 공유하지 않는다. 아래 명령 자리표시자를 실제 명령으로 바꾼다.

```text
작업 디렉터리: REPO_RELATIVE_WORKING_DIRECTORY
COMMAND --input REPO_RELATIVE_INPUT --output "${ARTIFACT_ROOT}/reports/RECEIPT_ID"
```

명령을 실행하지 않은 조사라면 **미실행**과 소스 조사 방법·근거를 기록한다.
정규화·생략한 내용이 결과 해석에 영향을 주면 그 범위를 밝힌다.

## 관측 결과

성공·실패·중단·결론 불충분을 그대로 기록한다. 요청한 CI를 성공으로 표시하지 않고,
미실행·미측정 값을 임의로 채우지 않는다. 같은 질문의 반복 실행은 표에 추가한다.

| 실행·비교 | 실행 여부와 상태 | 표본·반복 수 | 핵심 수치·오류 | 관측 근거 |
|---|---|---|---|---|
| 작성할 실행 | 실제 상태 또는 미실행과 이유 | 실제 수 또는 미측정과 이유 | 핵심 결과 | 소스 참조·공개 CI 링크·선별 산출물 |

### 산출물과 근거의 접근성

- 필요한 선별 산출물·hash:
- 외부 원시 자료의 논리 루트 기준 상대 위치 또는 인증 정보 없는 공유 참조:
- 접근 제한·보존 기간·만료가 재현에 미치는 영향:

원시 로그·큰 표·반복 snapshot·모델·데이터셋·바이너리를 붙이지 않는다.
임시 서명·인증이 포함된 다운로드 URL을 쓰지 않는다.

## 공유 전 점검

- [ ] 목적·비교 기준·기준 SHA와 재현 설정 또는 미실행 이유를 기록했다.
- [ ] 관측 사실과 추론, 로컬·CI·성능 근거, 성공·실패·중단·미측정을 구분했다.
- [ ] 공유 본문·명령·오류·발췌에 절대 파일 경로와 로컬 식별 정보·비밀 값이 없다.
- [ ] 작성자는 확인한 공개 GitHub 로그인명이며 외부 참조에 임시 인증 정보가 없다.
- [ ] 원시 자료를 복사하지 않아도 핵심 결과·한계·근거의 접근성을 이해할 수 있다.
- [ ] 같은 주제의 반복·정정·후속 기록을 연결하고 안내·자리표시자를 실제 결과로 바꿨다.
